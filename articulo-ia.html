Auto IA

Scripts que automatizan tu vida de estudiante

Como estudiantes de ingeniería de software, perdemos horas haciendo tareas mecánicas: renombrando archivos, organizando PDFs de clases o extrayendo texto de imágenes. La verdadera magia de la IA no es que te haga la tarea, sino que automatice el trabajo sucio.

El cerebro detrás de la operación

Antes de tirar código, hay que entender que la automatización moderna no es solo hacer un ciclo infinito. La IA combina la ejecución mecánica con capacidades cognitivas para tomar decisiones en tiempo real. Estos son los conceptos que dominan la industria actual:

Concepto ¿Qué significa en la práctica?
RPA (Automatización Robótica) El "músculo". Un bot que hace clics, mueve archivos y sigue reglas estrictas sin pensar.
Machine Learning (ML) El "cerebro". Algoritmos que aprenden patrones. Por ejemplo: predecir en qué carpeta va un PDF basándose en cómo organizaste tus descargas pasadas.
Procesamiento de Lenguaje (NLP) Los "ojos". Permite que el script lea el texto de un apunte escaneado y entienda que la palabra "Derivadas" pertenece a Cálculo.
Hiperautomatización El "jefe final". Conectar RPA, ML y NLP para automatizar flujos completos (ej. descargar el temario, leerlo, crear las carpetas del semestre y agendar fechas de exámenes automáticamente).

El Organizador Automático de Descargas

Este es un proyecto open-source que puedes montar hoy mismo. Usando Python y la librería watchdog, puedes crear un script que vigile tu carpeta de descargas y clasifique todo automáticamente integrando estos conceptos.

python 
import os
import shutil
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler

# Rutas de tus carpetas universitarias
ruta_descargas = "/Users/tu_usuario/Downloads"
ruta_materias = "/Users/tu_usuario/Universidad/Cuatri_3"

class Organizador(FileSystemEventHandler):
    def on_modified(self, event):
        for nombre_archivo in os.listdir(ruta_descargas):
            if nombre_archivo.endswith(".pdf"):
                origen = f"{ruta_descargas}/{nombre_archivo}"
                destino = f"{ruta_materias}/Lecturas/{nombre_archivo}"
                shutil.move(origen, destino)
                print(f"Movido: {nombre_archivo}")

event_handler = Organizador()
observer = Observer()
observer.schedule(event_handler, ruta_descargas, recursive=True)
observer.start()
