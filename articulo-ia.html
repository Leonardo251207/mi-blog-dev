Auto IA

Scripts que automatizan tu vida de estudiante

Como estudiantes de ingeniería de software, perdemos horas haciendo tareas mecánicas: renombrando archivos, organizando PDFs de clases o extrayendo texto de imágenes. La verdadera magia de la IA no es que te haga la tarea, sino que automatice el trabajo sucio.

El Organizador Automático de Descargas

Este es un proyecto open-source que puedes montar hoy mismo. Usando Python y la librería watchdog, puedes crear un script que vigile tu carpeta de descargas y clasifique todo automáticamente. Si le integras la API de OpenAI, el script puede leer tus PDFs, adivinar de qué materia son, y moverlos a la carpeta correcta del cuatrimestre.

python 
import os
import shutil
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler

# Rutas de tus carpetas universitarias
ruta_descargas = "/Users/tu_usuario/Downloads"
ruta_materias = "/Users/tu_usuario/Universidad/Cuatri_3"

class Organizador(FileSystemEventHandler):
    def on_modified(self, event):
        for nombre_archivo in os.listdir(ruta_descargas):
            # Lógica simple: mover PDFs a una carpeta específica
            if nombre_archivo.endswith(".pdf"):
                origen = f"{ruta_descargas}/{nombre_archivo}"
                destino = f"{ruta_materias}/Lecturas/{nombre_archivo}"
                shutil.move(origen, destino)
                print(f"Movido: {nombre_archivo}")

# Iniciar la vigilancia
event_handler = Organizador()
observer = Observer()
observer.schedule(event_handler, ruta_descargas, recursive=True)
observer.start()

¿Cómo mejorarlo con IA?

En lugar de solo mirar la extensión .pdf, podrías pasarle el nombre del archivo a una API local (como Ollama) o a la API de OpenAI, pedirle que identifique si es de "Álgebra" o "Programación Web", y enviarlo a su subcarpeta correspondiente.

"Automatizar un proceso que te toma 5 minutos al día te ahorrará más de 30 horas al año. Vale la pena programarlo."
