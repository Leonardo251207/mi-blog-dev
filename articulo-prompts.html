De cero a Frontend: Prompts para estudiar con IA

Cuando empecé mi tercer cuatrimestre, centrar un `div` parecía brujería. Flexbox y CSS Grid me daban dolores de cabeza, y los tutoriales de 3 horas en YouTube a veces me confundían más. Luego descubrí que la IA no solo sirve para hacer tareas, sino que es el **mejor tutor personal de programación**.

Aquí te dejo mis *prompts* (instrucciones) favoritos para que ChatGPT, Gemini o Claude te expliquen el desarrollo web sin morir en el intento.

1. El Prompt para entender Flexbox vs Grid

A veces la teoría es aburrida. Usa este prompt para que la IA te lo explique con analogías del mundo real:

prompt 
Actúa como un profesor de desarrollo web muy didáctico. 
Explícame la diferencia exacta entre CSS Flexbox y CSS Grid 
usando una analogía de la vida real (por ejemplo, organizar 
cajas en un almacén o mesas en un restaurante). 
Dame un ejemplo de código súper sencillo para cada uno.

2. El Prompt "Encuentra mi error"

¿Pasaste horas buscando por qué tu página se desborda en el celular? No te estreses, pídele a la IA que revise tu código.

prompt 
Tengo el siguiente código HTML y CSS. Estoy intentando 
[escribe lo que quieres lograr, ej: que estas 3 tarjetas 
se vean en fila], pero no funciona. 
¿Puedes revisar mi código, decirme dónde está el error 
y explicarme por qué falló? 

HTML:
[Pega tu HTML]

CSS:
[Pega tu CSS]

3. El Generador de Maquetación Base

Para no empezar con el síndrome de la hoja en blanco, pide una estructura básica semántica (excelente para el SEO).

prompt 
Escribe la estructura base en HTML5 para una página 
tipo "Blog". Debe incluir etiquetas semánticas como 
header, nav, main, article, aside y footer. 
Agrega comentarios en el código explicando para qué 
sirve cada etiqueta.
"El objetivo no es que la IA haga la página por ti, sino que te explique el código línea por línea para que tú puedas hacerlo solo la próxima vez."
