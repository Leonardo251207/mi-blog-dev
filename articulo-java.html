De C++ a Java: Cómo sobrevivir a la Programación Orientada a Objetos

Si acabas de terminar tu segundo cuatrimestre sintiéndote un dios de la programación porque lograste dominar los punteros en C++, tengo noticias para ti: el tercer cuatrimestre te presentará a Java y a la Programación Orientada a Objetos (POO).

1. Adiós a la gestión manual de memoria

En C++ estabas acostumbrado a usar new y delete para manejar la memoria. Si se te olvidaba, tenías una fuga de memoria. En Java, conocerás a tu nuevo mejor amigo: el Garbage Collector (Recolector de Basura).

2. Todo es un Objeto

A diferencia de C++, donde puedes tener funciones sueltas flotando en tu archivo, en Java todo debe vivir obligatoriamente dentro de una class. Cambiar este chip mental es lo que más cuesta al principio.

"Aprender Java después de C++ no es empezar de cero, es aprender a organizar tu lógica de una forma mucho más estructurada."
